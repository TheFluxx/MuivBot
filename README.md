`MuivBot` — Telegram-бот для студентов МУИВ с расписанием, поиском занятий, FAQ, событиями, поддержкой и отдельными панелями для администратора, старосты и преподавателя.

Бот работает на `aiogram`, хранит данные в PostgreSQL через `SQLAlchemy`, автоматически загружает расписание с сайта университета и поддерживает файлы расписания форматов `.xls` и `.xlsx`.

## Возможности

### Для студента
- просмотр своего расписания по группе;
- навигация по неделям, дням и месяцам;
- поиск по:
  - преподавателю;
  - аудитории;
  - предмету;
- просмотр посещаемости;
- раздел `FAQ`;
- просмотр событий;
- обращения в поддержку;
- настройки:
  - вечерняя рассылка расписания на завтра;
  - уведомления о событиях;
  - уведомления об изменениях расписания;
  - напоминания о ближайших парах.

### Для старосты
- вход в панель старосты;
- работа со своей группой;
- просмотр посещаемости студентов;
- отправка сообщений отдельному студенту или всей группе.

### Для преподавателя
- вход в панель учителя;
- выбор преподавателя внутри панели;
- просмотр своего расписания;
- ведение домашнего задания;
- напоминания о ближайших парах.

### Для администратора
- вход в админ-панель;
- просмотр статистики;
- управление пользователями;
- назначение старост и преподавателей;
- создание событий;
- логирование действий пользователей;
- выгрузка CSV-отчётов по действиям пользователей.

### Фоновые задачи
- автоматический мониторинг расписания на сайте МУИВ;
- обновление локальных файлов расписания;
- синхронизация расписания в базу данных;
- вечерняя рассылка расписания на завтра;
- напоминания о ближайших занятиях;
- уведомления об изменениях расписания.

## Требования

Перед запуском убедитесь, что у вас установлены:

- Python 3.11 или новее;
- PostgreSQL;
- `pip`;
- браузер Chromium для Playwright.

## Установка и запуск

### 1. Клонирование проекта

```bash
git clone https://github.com/TheFluxx/MuivBot.git
cd MuivBot
```

### 2. Создание виртуального окружения

#### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

#### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Установка браузера для Playwright

```bash
playwright install chromium
```

### 5. Настройка `.env`

Создайте файл `.env` в корне проекта и заполните его.

Пример:

```env
TOKEN=ваш_токен_бота

DB_DRIVER=postgresql+asyncpg
DB_USERNAME=postgres
DB_PASSWORD=postgres
DB_HOST=localhost:5432
DB_NAME=muivbot

ADMIN_LOGIN=admin
ADMIN_PASSWORD=admin_password

STAROSTA_LOGIN=starosta
STAROSTA_PASSWORD=starosta_password

TEACHER_LOGIN=teacher
TEACHER_PASSWORD=teacher_password
```

### 6. Запуск бота

```bash
python main.py
```

После запуска бот:

- создаст таблицы в базе данных;
- загрузит расписание из папки `schedules`;
- запустит мониторинг расписания;
- включит фоновые рассылки и напоминания.

## Как работает расписание

Бот использует два источника данных:

1. локальные Excel-файлы в папке `schedules`;
2. автоматический мониторинг страницы расписаний МУИВ.

Монитор:

- периодически открывает страницу расписания;
- ищет новые или обновлённые файлы;
- скачивает их в `schedules`;
- после обновления заново загружает расписание в память и в базу данных.

Поддерживаются форматы:

- `.xls`
- `.xlsx`

## Команды бота

Основные команды:

```text
/start          - главное меню
/search         - поиск по расписанию
/group          - поиск по группе
/date           - расписание на дату
/teacher        - поиск по преподавателю
/room           - поиск по аудитории
/subject        - поиск по предмету
/today          - расписание на сегодня
/tomorrow       - расписание на завтра
/faq            - часто задаваемые вопросы
/help           - список команд
```

Служебные команды:

```text
/admin          - вход в админ-панель
/starosta       - вход в панель старосты
/teacher_panel  - вход в панель учителя
```

## Первый запуск

При первом запуске важно проверить:

1. база данных доступна;
2. `.env` заполнен корректно;
3. Playwright установлен вместе с Chromium;
4. в папке `schedules` есть хотя бы один файл расписания или монитор может скачать его с сайта.

## Полезные замечания

- Если сайт МУИВ временно недоступен, бот продолжит работать на уже загруженном расписании.
- Если в логах появляются предупреждения мониторинга, это не всегда критическая ошибка: бот может продолжить работу с локальными файлами.
- При добавлении нового Excel-файла расписания иногда достаточно просто перезапустить бота, чтобы он заново перечитал папку `schedules`.
- Для корректной работы поиска по преподавателю, аудитории и предмету бот строит внутренний индекс занятий из всех загруженных файлов расписания.

